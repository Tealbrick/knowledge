# Source history

This standalone Knowledge repository was initialized on 2026-08-30 from the
Knowledge product boundary in Tealbrick’s portfolio workspace. Its initial
snapshot included uncommitted work; it was not a reproducible export of a
single donor commit. Subsequent changes are tracked in this repository.

The repository includes the Knowledge Program, browser frontend, adapters,
tests and deployment configuration. Required shared UI and extension-settings
source is bundled under `.sdk/` so builds do not require the portfolio checkout.
Runtime data, credentials and operator-specific deployment records are not
part of the public source distribution.
